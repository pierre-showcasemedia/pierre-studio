## Return shoots

A second visit to a property goes on the same booking as an **additional shoot**: a return trip, a pickup, a reshoot or a twilight return.

- Add it from the booking, with its own date, time and shooter. It gets its own calendar event.
- An added item that costs more goes on its own invoice; a reshoot for a field mistake doesn't.
- Additional shoots count in the Shooter pay report. See [Shooter pay](/admin/sops/shooter-pay).
